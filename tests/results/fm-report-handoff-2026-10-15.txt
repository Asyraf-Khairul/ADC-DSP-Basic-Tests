Implementation changes
- receiver_dsp/fft.cpp: native-width unsigned loop indices avoid repeated
16-bit truncations. Signed 16-bit sample intermediates, rounding and wrapping
were retained. The quarter-turn index now uses span >> 1, avoiding an unused
negative shift at stage zero.
- receiver_dsp/rx_dsp.cpp: zoom 1 copies spectrum pixels directly instead of
using the general division-based zoom loop; other zoom levels retain that loop.
- Corrected magnitudes for all 256 bins are calculated once per display update
and reused for scaling instead of calculating each correction twice.
- Repeated magnitudes below 256 reuse the exact calculated pixel within that
update. The validity flags reset for each update, so changing display scale
cannot reuse stale results. Larger values use the original expression.
- The extra local spectrum storage is 800 bytes within the existing 16 KiB
core1 stack. No new persistent tables or heap allocations. This is not a
runtime stack high-water measurement.
- Clock, sampling rates, filter coefficients, demodulation calculations,
gain, diagnostic counters and spectrum cadence were not changed. No fast-math.
All signal-dependent work stays inside the original inclusive timer, which
measures process_samples plus stream_audio. Spectrum updates remain every
64 receiver blocks. Diagnostic window bookkeeping is measured separately.

Setup and method
Pico clock 120 MHz; aggregate ADC rate 480 kword/s, 240 ksample/s per channel;
2048 ADC words and 64 audio samples per block, audio at 15 kHz. Nominal block
rate 234.375/s; firmware deadline 4266 us. Mixer disconnected; retained
470 ohm/1 kohm dividers. Generator CH1 to GP27: user-confirmed 8 kHz sine
carrier, displayed 300 mVpp, High-Z, +2.5 V offset, internal sine FM at 500 Hz
with 500 Hz deviation. GP26 biased near midscale. The 1.635 V reading preceded
the corrected baseline and was carried forward, not remeasured after flashing.
Fresh complete GP27 mean/Vpp/min/max scope readings were not supplied.

Preset 4: FM, IF-I, tuning +8000 Hz, bandwidth index 2, manual AGC setting 4,
gain_log2=0 (gain x1, not mute), volume 25%. Remaining settings: sq=-1,
hang=3, swap=0, iqcorr=0, deemph=0, bass=0, treble=0, blanker=0, notch=0,
nr=0, smooth=10, threshold=1, cw=700.

Each candidate was built in Release (-O3, -fwrapv), with BENCH_SELF_TEST=OFF

Validation and limitations
43 fresh-process host receiver scenarios, 512 blocks each, produced identical
PCM, magnitude, spectrum pixels and scale versus the frozen reference.
Includes FM real-I gain x1 at 250/500 Hz deviation and modulation off,
other receiver modes/settings, and zoom 2/3/4. Another 9000 FFT/IFFT cases
covered sizes 1..256, silence, rails and seeded random full-range inputs;
all were bit-identical. Host numerical tests are not hardware numerical or
demodulation-quality measurements. I confirmed the OLED, encoder and both
buttons were responsive after v2 startup, before the timed interval; this
was not a separately timestamped in-window check. No photos were archived.
The recovered 500 Hz output tone, modulation-off suppression, deviation
response, distortion and speaker audibility have NOT been established.
AM hardware timing has not been retested on this new binary. The observed
FM timing pass is not a guarantee for all signals, effects or longer runs.
